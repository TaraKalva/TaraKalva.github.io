Instagram Likes Prediction Using Regression Techniques

A structured Scikit-learn regression pipeline designed to forecast social post engagement from temporal and interaction-based signals while handling heavy right-skew in like counts.

Project Overview

Social engagement distributions are inherently skewed—a handful of viral posts create extreme outliers that distort standard linear loss functions. This project constructs an end-to-end Scikit-learn pipeline to predict Instagram post likes cleanly and reproducibly.

Modeling Workflow

Stage 01

Feature Engineering

Extracted temporal publishing attributes and interaction-based engagement signals.

Stage 02

Preprocessing

Cleaned missing values, encoded categorical variables, and stabilized variance via target log transformation.

Stage 03

Model Benchmarking

Evaluated five candidate regression models uniformly using 10-fold cross-validation and MSE.

Stage 04

Hyperparameter Tuning

Applied GridSearchCV to select optimal regularization and estimator parameters for final generalization.

Key Analytical Takeaways

  • Target Log Transformation: Compressing long-tail like counts stabilized residual variance and improved regression fit stability across folds.
  • Leak-Free Pipeline Encapsulation: Wrapping encoding and transformations inside Scikit-learn pipelines ensured 10-fold cross-validation scores remained strictly leak-free.
  • Systematic Model Selection: Comparing five regression families side-by-side via MSE and tuning with GridSearchCV provided a data-backed choice rather than relying on a single baseline estimator.
